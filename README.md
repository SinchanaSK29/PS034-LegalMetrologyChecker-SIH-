## 🎯 Problem Statement

Manual checking of packaged commodity labels can be time-consuming and may require checking multiple details such as:

- Product name
- Net quantity
- Maximum Retail Price (MRP)
- Manufacturer information
- Date information
- Other mandatory declarations

There is a need for a simple system that can assist in identifying these details from product labels and present them clearly for compliance screening.

---

## 💡 Solution

MetroLens provides an **image-based compliance screening prototype**.

The user uploads or captures an image of a packaged product label.

The system then:

1. 📷 Scans the product label image
2. 🔎 Extracts text using OCR
3. 📋 Identifies important product information
4. ✅ Checks the detected information against the required checklist
5. 📊 Displays the compliance status and relevant messages

The goal is to make the initial screening process simpler and easier to understand.

---

 ##✨ Current Features

 📷 Product Label Scanning
Allows the user to upload a packaged commodity label image.

 🔎 OCR-Based Text Extraction
Uses OCR to extract text from the product label.

 💰 MRP Detection
Attempts to identify the Maximum Retail Price from the extracted text.
 📦 Net Quantity Detection
Attempts to identify the declared net quantity of the product.

 🏭 Manufacturer Information
Identifies manufacturer-related information from the label.

 📅 Date Detection
Detects relevant date information present on the product label.

 ✅ Compliance Checklist
Displays whether important information has been detected.

 📋 Compliance Status
Provides a simple status and message based on the detected information.
