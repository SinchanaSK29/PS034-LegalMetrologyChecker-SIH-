# MetroLens 🔎

SIH 2026 – PS034 Demo Prototype

MetroLens is a **prototype demo** developed for **Smart India Hackathon 2026 – PS034**.

The demo explores how packaged commodity labels can be scanned and checked for important compliance-related information using OCR.

## 🎯 Demo Objective

To demonstrate a simple workflow where a product label image is:

**Scanned → Text extracted → Key details identified → Compliance status displayed**

✨ Demo Features

- 📷 Product label image scanning
- 🔎 OCR-based text extraction
- 💰 MRP detection
- 📦 Net quantity detection
- 🏭 Manufacturer information detection
- 📅 Date information detection
- ✅ Compliance checklist
- 📋 Compliance result display

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Tesseract.js
- OCR Detective
- GitHub Pages to host
